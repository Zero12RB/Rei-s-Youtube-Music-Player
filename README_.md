A Windows-based application that turns your computer into a receiver for music or video streamed from your phone (via the **YouTube TV Cast / Link with TV code** feature)—all while keeping the YouTube window **completely hidden from your screen**.

## ✨ Key Features

* 🙈 **Completely Off-Screen:** Shifts the YouTube TV window outside the visible display area, allowing you to work or play games without any interruptions.
* ⚡ **Resource Efficiency:** Automatically optimizes concurrent Edge processes (removing redundant or duplicate tabs) to save RAM.

## 📋 System Requirements

* **Operating System:** Windows 10 / Windows 11
* **Browser:** Microsoft Edge (installed by default on Windows)
* **Required Extensions:** [Youtube TV ON PC](https://chromewebstore.google.com/detail/jldjbkccldgbegjpggphaeikombjmnkh?utm_source=item-share-cb), [UBlock Origin](https://ublockorigin.com/)
* **Permissions:** Run as **Administrator**
> ⚠️ **Note :** Must set the Language on Youtube to ``ENGLISH ( US ) `` , OTherwise it will not work.

## 🚀 Usage Instructions

### 1. Install Extensions & Launch the Script
Install the following two extensions in the Edge browser: [Youtube TV ON PC](https://chromewebstore.google.com/detail/jldjbkccldgbegjpggphaeikombjmnkh?utm_source=item-share-cb) and [UBlock Origin](https://ublockorigin.com/).
Right-click the `YTHeadless.exe` file and run it. Wait for both windows to open.
A control panel will appear; select `1. Open YouTube`.

### 2. Connecting via Mobile (Cast)
1. Open the YouTube app on your mobile device.
2. Tap the **Cast** icon.
3. Select **Link with TV code**.
4. Open the YouTube window using the **`3. Show YouTube Window`** button on the application panel to retrieve the 12-digit code (or scan the QR code) found under *Settings > Link with TV code*.
5. Once connected, select **`2. Hide YouTube Off-Screen`** or **`4. Hide Panel to Tray`** to completely hide the application.

## 🛠️ Panel Options Structure

| Button | Function |
| :--- | :--- |
| **1. Open YouTube** | Launches the YouTube TV interface via Microsoft Edge (used for logging in and pairing your device). |
| **2. Hide YouTube Off-Screen** | Moves the active YouTube window outside the screen coordinates. |
| **3. Show YouTube Window** | Brings the YouTube window back onto the main screen for adjustments or settings. |
| **4. Hide Panel to Tray** | Minimizes the control panel to the system tray. |
| **Auto-Hide on Launch** | Toggles the mode that automatically hides the application completely upon startup. |
